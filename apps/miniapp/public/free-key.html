Get a free AI key

About a minute. Free tier is enough for months of logging.

SnapBite doesn't call an AI on its own bill — it calls the provider you choose, with your key. That is why it can stay free to run, and why nobody else's usage limits your logging. The key is stored encrypted in SnapBite's database and used only to analyse the meals you send.

Easiest: Google Gemini

1. Open Google AI Studio

Go to aistudio.google.com/apikey and sign in with a Google account.

2. Create an API key

Press Create API key, pick any project (the default is fine), and copy the string that starts with AIza.

3. Paste it into SnapBite

Open @SnapBiteAI_bot → the menu button → Settings → choose Gemini → paste the key → Save. Then send a meal.

Prefer OpenAI or DeepSeek?

OpenAI — platform.openai.com/api-keys. Needs billing set up on the account.

DeepSeek — platform.deepseek.com/api_keys. Cheap per meal, no free trial.

Any OpenAI-compatible endpoint works too: pick Custom in Settings and paste the base URL and key.

What it costs

A meal is one small vision or text call. On Gemini's free tier that's nothing; on a paid key it is a fraction of a cent per meal. SnapBite itself has no subscription.

If it stops working

  • Quota or rate limit — the provider's own limit, not SnapBite's. Add a fallback provider in Settings and SnapBite will switch to it automatically.
  • Wrong region — some providers refuse some countries. Use a fallback, or a provider that serves yours.
  • Lost the key — create a new one; paste it over the old one in Settings.

You can also log meals without any key: add them by hand in the app, and use targets, streaks and the weekly recap. The key is only needed for AI photo and text analysis.
